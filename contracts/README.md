1. NoEnglishOnlyContract；
2. NoSchemaWithoutBusinessMeaning；
3. NoContractWithoutExample；
4. NoExampleWithoutBoundary；
5. NoModuleWithoutContractTest；
6. NoFindingWithoutEvidenceTrace；
7. NoReleaseWithoutBenchmarkGate。
