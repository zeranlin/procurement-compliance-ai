22项≠22个关键词 \boxed{ 22项 \neq 22个关键词 }

中文业务释义： 规则 ≠ 法规文本仅。

LatestPolicy≠ApplicablePolicy \boxed{ LatestPolicy \neq ApplicablePolicy }

中文业务释义： 最新发布 / 当前最新政策 ≠ 适用政策 / 适用法规。

PolicyPreference≠IllegalDiscrimination \boxed{ PolicyPreference \neq IllegalDiscrimination }

中文业务释义： 政策偏好 ≠ Illegal歧视/不合理排斥。

Requirement≠Restriction \boxed{ Requirement \neq Restriction }

中文业务释义： 业务要求 ≠ 限制。

RuleHit≠FinalViolation \boxed{ RuleHit \neq FinalViolation }

中文业务释义： 规则命中 ≠ 最终违规认定。

Detection≠Decision \boxed{ Detection \neq Decision }

中文业务释义： 风险检测 ≠ 判断结论。

LegalCitation≠LegalSupport \boxed{ LegalCitation \neq LegalSupport }

中文业务释义： 法条引用 ≠ 法条对当前结论的实质支持。

LLM≠ComplianceEngine \boxed{ LLM \neq ComplianceEngine }

中文业务释义： 大语言模型 ≠ 合规引擎。

DeterministicRule⇒CalculatorFirst \boxed{ DeterministicRule \Rightarrow CalculatorFirst }

OverallAccuracy≠ComplianceReliability \boxed{ OverallAccuracy \neq ComplianceReliability }

中文业务释义： 总体准确率 ≠ 合规可靠性。

HighRisk⇒Evidence+Audit+HumanEscalation \boxed{ HighRisk \Rightarrow Evidence + Audit + HumanEscalation }

中文业务释义： 高风险 ⇒ 证据 + 审计 + 升级人工复核。
