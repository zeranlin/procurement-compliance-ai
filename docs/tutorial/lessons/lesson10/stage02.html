一、Weight 显存为什么和 bit 数直接相关？

若模型有 PP 个参数，每个参数使用 bb bit，则仅 Weight 的理论存储量近似：

Memoryweights≈P⋅b8 \boxed{ Memory_{weights}\approx \frac{P\cdot b}{8} }

因此理论上：

16 bit → 每参数约 2 bytes
8 bit  → 每参数约 1 byte
4 bit  → 每参数约 0.5 byte

所以从 16 bit 到 8 bit：

Weight 存储大约减半。

从 16 bit 到 4 bit：

Weight 存储大约变成四分之一。

但真实推理显存还包括：

KV Cache
Runtime Buffer
CUDA Context
Workspace
Batch Metadata

所以：

WeightMemorySaving≠TotalVRAMSaving \boxed{ WeightMemorySaving \neq TotalVRAMSaving }

二、FP16 与 BF16

两者都是 16 位浮点。

FP16：

尾数精度相对更高，但动态范围较窄。

BF16：

动态范围更大，但尾数精度较低。

工程上最终选哪个，需要看：

GPU支持
模型训练精度
Kernel实现
推理引擎

所以：

DataTypeChoice=MemoryDecision+NumericalDecision+KernelDecision \boxed{ DataTypeChoice = MemoryDecision + NumericalDecision + KernelDecision }

三、整数量化怎样映射浮点数？

一种常见抽象：

q=round(xs)+z q= round\left(\frac{x}{s}\right)+z

其中：

  • ss：Scale，缩放因子；
  • zz：Zero Point，零点。

反量化：

x̂=s(q−z) \hat{x}=s(q-z)

通常：

x̂≠x \hat{x}\neq x

量化误差：

eq=x−x̂ \boxed{ e_q=x-\hat{x} }

因此低 bit 的核心交换关系是：

LessMemory↔MoreApproximation \boxed{ LessMemory \leftrightarrow MoreApproximation }

四、Symmetric、Asymmetric 与 Scale 粒度

Symmetric Quantization

对称量化

数值范围围绕 0 对称。

Asymmetric Quantization

非对称量化

允许使用 Zero Point，更适合偏移分布。

Scale 还可以分为：

Per-Tensor
整个Tensor一个Scale

Per-Channel
每个Channel一个Scale

Group-wise
每组Weight一个Scale

一般来说：

粒度越细，越容易降低量化误差，但元数据和 Kernel 复杂度更高。

所以：

FinerGranularity≠FreeAccuracy \boxed{ FinerGranularity \neq FreeAccuracy }

五、Weight-only 与 Activation Quantization

Weight-only Quantization

只量化权重

例如：

Weight = INT4
Activation = FP16/BF16

重点是：

减少 Weight 存储和 Weight 读取带宽。

但：

StoragePrecision≠ComputePrecision \boxed{ StoragePrecision \neq ComputePrecision }

Weight 存成 INT4，不代表整个算子都在 INT4 中计算。

Activation Quantization

激活量化

Activation 会随输入动态变化，并可能存在：

Outlier

离群值

所以一般比固定 Weight 更难量化。

因此：

WeightQuantization≠ActivationQuantization \boxed{ WeightQuantization \neq ActivationQuantization }

六、Quantization Calibration

这里的 Calibration 是：

用代表性样本观察数值分布，为 Scale、Clipping Range 等量化参数提供依据。

它不是第九课的 Confidence Calibration。

所以：

QuantizationCalibration≠ConfidenceCalibration \boxed{ QuantizationCalibration \neq ConfidenceCalibration }

而且校准数据应该尽量接近生产：

中文采购长文
RAG长上下文
结构化输出
真实任务分布

七、PTQ 与 QAT

PTQ

Post-Training Quantization 训练后量化

优点：

成本低
速度快
不必完整重训

QAT

Quantization-Aware Training 量化感知训练

训练时模拟量化误差，让模型适应低精度表示。

通常：

成本更高，但在更激进量化场景下可能更有价值。

八、为什么量化后不一定更快？

如果：

低bit Kernel不成熟
硬件不擅长该格式
频繁反量化
Batch形态不匹配

就可能：

显存省了，但速度没有提升。

所以：

SmallerModel≠FasterModel \boxed{ SmallerModel \neq FasterModel }

真正性能收益必须经过：

真实硬件
真实Engine
真实Workload

实测。
