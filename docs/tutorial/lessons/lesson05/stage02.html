二、先锁死本阶段 5 个核心心智模型

今天真正需要长期记住的只有五句话。

心智模型 1：SFT 本质仍然是 Next Token Prediction

SFT 并没有给 Transformer 安装一个新的“问答模块”。

它仍然只干一件事：

根据前面的 Token，预测下一个 Token。

所以：

SFT=受监督的NextTokenPrediction \boxed{ SFT = 受监督的 Next Token Prediction }

所谓“监督”，就是：

我们已经知道这个位置正确的下一个 Token 应该是什么。

心智模型 2：Forward 负责“做答案”，Loss 负责“判多少分”

Forward：

模型根据当前参数做一次预测。

Loss：

拿预测结果和专家答案比较。

所以：

Forward
=
当前模型会怎么答？

Loss
=
这个回答离专家答案有多远？

这两个角色必须分开。

心智模型 3：Gradient 不是“错误大小”，而是“参数应该往哪边改”

Loss 只告诉我们：

错得多不多。

Gradient 才告诉我们：

每个可训练参数应该增一点还是减一点。

所以：

Loss≠Gradient \boxed{ Loss \neq Gradient }

更准确地说：

Loss
告诉你：
总体犯错程度

Gradient
告诉你：
每个参数该怎么动

心智模型 4：Backward 计算修改建议，Optimizer 才真正改参数

这是非常容易混淆的一对。

loss.backward()

主要负责：

算 Gradient。

而：

optimizer.step()

才负责：

真正更新参数。

所以：

Backward≠ParameterUpdate \boxed{ Backward \neq ParameterUpdate }

正确顺序是：

Backward
↓
得到 Gradient
↓
Optimizer Step
↓
参数变化

心智模型 5：LoRA 训练时，Base Model 负责计算，但主要不被更新

以后我们会正式讲 LoRA。

今天先建立一个准确心智模型：

Base Model
大量参数
被冻结
      │
      │ 仍参与 Forward
      │ 仍传递计算信号
      ▼
LoRA Parameters
少量可训练参数
      │
      ▼
接收 Gradient
      │
      ▼
Optimizer 更新

所以：

冻结 ≠ 不参与计算。

更准确地说：

Base Model 仍然参与 Forward 和反向信号传播，但被冻结的权重本身不由 Optimizer 更新。

这句话后面非常重要。

所以：

正确答案概率越高⇒Loss越低 \boxed{ 正确答案概率越高 \Rightarrow Loss越低 }

十七、Backward 在问什么？

Forward 问：

当前参数给出什么结果？

Backward 问：

如果希望 Loss 下降，每个可训练参数应该往哪个方向动？

这是完全不同的问题。

十八、举一个极简例子

假设模型只有一个参数：

w w

当前：

w = 2.0

Loss：

L = 3.0

我们想知道：

如果把 ww 稍微增加一点，Loss 会增加还是下降？

这就是：

∂L∂w \frac{\partial L}{\partial w}

十九、Gradient 最简单怎么理解？

Gradient

梯度

例如：

∂L∂w=+0.8 \frac{\partial L}{\partial w} = +0.8

可以粗略理解：

往正方向增加 ww，Loss 会升高。

那么为了降低 Loss：

我们应该让 ww 往负方向走一点。

如果：

∂L∂w=−0.8 \frac{\partial L}{\partial w} = -0.8

则意味着：

增加 ww 有助于降低 Loss。

二十、所以 Gradient 同时包含两类信息

方向

+
或
-

告诉：

参数往哪边移动。

大小

例如：

0.001

和：

12.5

代表：

Loss 对这个参数的敏感程度不同。

所以：

Gradient=Direction+Sensitivity \boxed{ Gradient = Direction + Sensitivity }

二十一、Backward 为什么叫“反向”？

因为计算方向和 Forward 大致相反。

   ↓

   ↓

   ↓

   ↓

   ↓

它从最终 Loss 出发：

二十三、这里真正依赖的是 Chain Rule

Chain Rule

链式法则

假设：

w→h→z→L w \rightarrow h \rightarrow z \rightarrow L

我们想知道：

w w

对最终：

L L

的影响。

通过链式法则：

∂L∂w=∂L∂z⋅∂z∂h⋅∂h∂w \frac{\partial L}{\partial w} = \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial h} \cdot \frac{\partial h}{\partial w}

不用计算。

只记：

最终错误可以沿着计算链，一层一层传回早期参数。

二十七、最简单的 Gradient Descent

最基本公式：

θnew=θold−η∇θL \theta_{\text{new}} = \theta_{\text{old}} - \eta \nabla_\theta L

这里：

  • θ\theta：参数；
  • LL：Loss；
  • ∇θL\nabla_\theta L：Gradient；
  • η\eta：Learning Rate。

真正记住：

参数沿着让 Loss 下降的方向移动一小步。

二十八、Learning Rate 是什么？

Learning Rate

学习率

就是公式里的：

η \eta

可以理解成：

每次相信 Gradient 多少。

如果 Learning Rate 很小：

每次只改一点点

如果太大：

一下跳太远

=

第二，Forward 负责产生预测，Cross Entropy 把预测和正确 Token 比较后得到 Loss。

本阶段最后只记一句话

一次 SFT Step 的本质，就是模型先用当前参数预测下一个 Token，再用 Cross Entropy 衡量它与专家答案的差距，通过 Backpropagation 把这份错误沿 Transformer 反向传成 Gradient，最后由 Optimizer 按 Learning Rate 对可训练参数做一次小更新；成千上万次这样的微小更新，最终才把 P(Response \mid Prompt) 逐渐塑造成我们希望的政府采购专业行为。
