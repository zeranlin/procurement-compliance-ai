A. 本阶段核心心智模型（前置）

  1. DomainGap ≠ BehaviorGap。不懂领域和不会按要求做任务，是两个不同问题。
  2. TrainingChoice 必须由 ErrorDiagnosis 驱动。先判断错误发生在哪一层，再决定 CPT、SFT、RAG 或 Agent。
  3. DomainCompetence ≠ InstructionBehavior。领域底座能力和任务行为能力必须分层看。
  4. CPT = WorldModeling，SFT = BehaviorShaping。CPT 主要塑造领域表示，SFT 主要塑造任务行为。
  5. CourseOrder ≠ ProductionTrainingGraph。课程先学 SFT 后学 CPT，不代表真实训练顺序就应该如此。

一、先锁死本阶段最重要的一句话

CPT 和 SFT 都会改变模型参数。

但它们优化的不是同一个问题。

DomainGap≠BehaviorGap \boxed{ DomainGap \neq BehaviorGap }

Domain Gap

领域分布差距

指：

模型对政府采购语言、结构、术语和统计分布本身不够熟。

Behavior Gap

任务行为差距

指：

模型虽然理解输入，但不会按要求完成任务、遵守格式或执行输出协议。

所以：

CPT主要解决DomainGap \boxed{ CPT 主要解决 DomainGap }

SFT主要解决BehaviorGap \boxed{ SFT 主要解决 BehaviorGap }

三、CPT 到底学什么？

CPT 仍然做：

Causal Language Modeling

因果语言建模

它学习：

政府采购术语怎样共同出现
采购文件结构怎样延续
领域语言有哪些统计模式
长文档章节之间怎样关联
行业采购文本是什么风格

所以更接近：

CPT=LearnDomainDistribution \boxed{ CPT = LearnDomainDistribution }

它在提升的是：

模型的领域底座。

四、SFT 到底学什么？

SFT：

Supervised Fine-Tuning

监督微调

通常有明确的：

Input
输入

Target Response
目标回答

例如：

输入：
某采购条款

目标输出：
risk_type
reason
evidence
recommendation

SFT 主要学习：

任务格式
输出风格
指令遵循
Schema结构
回答边界
拒答行为

所以：

SFT=LearnTaskBehavior \boxed{ SFT = LearnTaskBehavior }

五、核心心智模型 ②：Language Modeling Competence 和 Instruction Behavior 是两个不同能力层

一个模型可能：

很懂采购语言
但不会按JSON输出

也可能：

JSON输出非常稳定
但对采购概念理解浅

所以：

DomainCompetence≠InstructionBehavior \boxed{ DomainCompetence \neq InstructionBehavior }

前者偏：

CPT。

后者偏：

SFT。

这就是为什么两者不能互相简单替代。

六、什么时候优先做 CPT？

典型信号包括：

大量高质量无标注领域文本存在

模型对领域术语和结构理解不稳定

长采购文档语言建模明显弱

行业语料分布和通用语料差异大

SFT样本有限但无标注Corpus很大

希望提升的是多任务共享的领域底座

例如：

不只是风险识别弱，而是多个采购任务都表现出领域理解不足。

这时更像：

SharedDomainRepresentationGap \boxed{ SharedDomainRepresentationGap }

CPT 更有价值。

七、什么时候优先做 SFT？

典型信号包括：

模型基本理解输入
但不会按要求回答

格式不稳定
Schema不遵守
不会拒答
任务边界不清
分类标签不稳定
解释模板不一致

这类问题更像：

TaskAlignmentGap \boxed{ TaskAlignmentGap }

所以优先：

SFT。

八、核心心智模型 ③：如果问题只发生在一个任务上，先怀疑 Behavior；如果多个任务都受影响，才更像 Domain Foundation 问题

假设：

风险分类
表现差

但：

术语解释正常
文件理解正常
问答正常

那不一定需要 CPT。

可能只是：

反过来，如果：

风险识别差
文件问答差
术语理解差
长文档摘要也差

多个任务共同受影响，

就更像：

共享领域表示不足。

所以：

SingleTaskFailure优先检查BehaviorGap \boxed{ SingleTaskFailure 优先检查 BehaviorGap }

CrossTaskFailure更值得检查DomainGap \boxed{ CrossTaskFailure 更值得检查 DomainGap }

九、什么问题其实既不该 CPT，也不该 SFT？

非常重要。

如果用户问：

二十八、本阶段最重要的 8 个核心心智模型

心智模型 ①：DomainGap ≠ BehaviorGap。不懂领域和不会按要求做任务，是两个不同问题。

心智模型 ②：TrainingChoice 必须由 ErrorDiagnosis 驱动。先判断错误发生在哪一层，再决定 CPT、SFT、RAG 或 Agent。

心智模型 ③：DomainCompetence ≠ InstructionBehavior。领域底座能力和任务行为能力必须分层看。

心智模型 ④：CPT = WorldModeling，SFT = BehaviorShaping。CPT 主要塑造领域表示，SFT 主要塑造任务行为。

心智模型 ⑤：CourseOrder ≠ ProductionTrainingGraph。课程先学 SFT 后学 CPT，不代表真实训练顺序就应该如此。

心智模型 ⑥：StructuralCompatibility ≠ BehavioralCompatibility。Checkpoint 或 Adapter 能加载，不代表行为一定兼容。

心智模型 ⑦：FoundationMetric ≠ BehaviorMetric。CPT 与 SFT 的评测必须分层，不能用一个指标替代另一个。

心智模型 ⑧：MoreTech ≠ BetterSystem。真正专业的系统优先采用最小但足够的干预，而不是把所有技术都堆上去。
