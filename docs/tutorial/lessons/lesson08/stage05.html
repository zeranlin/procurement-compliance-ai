A. 本阶段核心心智模型（前置）

  1. CorpusShare ≠ TrainingShare。原始数据占比只是“你有什么”，训练占比才决定“模型实际看什么”。
  2. SamplingPolicy = GradientAllocationPolicy。采样策略本质上是在给不同能力分配训练梯度。
  3. Oversampling = SignalAmplification + DuplicateExposure。过采样能强化稀有能力，也会放大重复和过拟合风险。
  4. SameTrainingShare ≠ SameExposure。同样的训练占比，对不同大小的 Unique Token Pool 会产生完全不同的重复曝光。
  5. Eligibility ≠ Priority。Filter 决定能不能训练，Weight 决定有资格的数据训练多频繁。

一、先锁死本阶段最重要的一句话

CPT 的 Data Mixture 不是：

“把所有语料混在一起然后随机抽。”

更准确地说：

TrainingDistribution=DesignedDistribution \boxed{ TrainingDistribution = DesignedDistribution }

也就是说：

模型最终更像什么，不只由你收集了什么数据决定，也由训练时哪些数据被看了多少次决定。

因此：

SamplingPolicy=GradientAllocationPolicy \boxed{ SamplingPolicy = GradientAllocationPolicy }

翻译成人话：

采样策略本质上是在决定训练梯度被分配到哪些数据分布上。

五、最简单的采样权重怎样定义？

假设有 KK 个数据桶：

D1,D2,…,DK D_1,D_2,\dots,D_K

每个桶目标采样概率：

pi p_i

满足：

∑i=1Kpi=1 \sum_{i=1}^{K}p_i=1

训练时每次选择一个数据桶：

Di∼p D_i\sim p

然后从该桶里抽样本。

这就是：

Weighted Sampling

加权采样

如果目标比例是：

法规 15%
采购文件 35%
公告 20%
合同履约 10%
行业专项 15%
解释文本 5%

那么训练的真实数据流应该尽量接近：

这套目标分布。

六、Natural Sampling：按原始数据量采样什么时候有问题？

自然采样可以概念化为：

pi=Ni∑jNj p_i = \frac{N_i}{\sum_jN_j}

其中：

Ni=第i类数据的Token数 N_i = 第i类数据的Token数

优点：

简单、自然、不会人为放大稀有桶。

但缺点是：

大数据桶会完全主导梯度。

例如公告有：

40B tokens

法规只有：

4B tokens

那么自然采样下公告曝光约 10 倍。

如果公告高度模板化，

你实际上可能在训练：

“公告语言模型”。

而不是：

“政府采购领域模型”。

所以：

RawVolume可能放大LowValueDistribution \boxed{ RawVolume 可能放大 LowValueDistribution }

七、Temperature Sampling：为什么要“压平”大数据桶？

一种常见思路是：

Temperature Sampling

温度采样

概念上：

pi∝Niα p_i \propto N_i^\alpha

其中：

0<α≤1 0<\alpha\leq1

当：

α=1 \alpha=1

就是自然采样。

当：

α<1 \alpha<1

大数据桶的优势会被压缩，

小数据桶相对获得更多曝光。

例如：

公告
40B

法规
4B

原始规模相差：

10× 10\times

经过温度变换以后，

训练曝光差距可以显著缩小。

核心不是记公式。

而是理解：

TemperatureSampling=ReduceSizeDominance \boxed{ TemperatureSampling = ReduceSizeDominance }

即：

降低“谁数据多谁统治训练”的现象。

八、核心心智模型 ③：Oversampling 会放大信号，也会放大重复

如果一个高质量小桶只有：

500M tokens

但我们希望它贡献：

10%的训练Token

它可能会被反复抽到很多次。

这叫：

Oversampling

过采样

好处：

让稀有但重要能力获得足够训练曝光。

风险：

同一文档被重复看到
固定表达被过度记忆
小桶更容易过拟合
Benchmark近似样本风险被放大

所以：

Oversampling=SignalAmplification+DuplicateExposure \boxed{ Oversampling = SignalAmplification + DuplicateExposure }

不能只看：

“这个桶很重要，所以多抽。”

还要看：

它到底能承受多少重复曝光。

九、Exposure：专业分析必须看“看过多少次”，不能只看采样比例

假设某一桶：

Corpus Size
=
1B tokens

训练过程中从该桶累计抽取：

5B tokens

可以说：

平均 Token Exposure 约为 5 次。

概念化：

Exposurei=SampledTokensiUniqueTokensi Exposure_i = \frac{SampledTokens_i}{UniqueTokens_i}

这不是严格等同于传统 Epoch，

因为：

但它是非常重要的工程直觉：

TrainingShare+CorpusSize⇒Exposure \boxed{ TrainingShare + CorpusSize \Rightarrow Exposure }

同样 10% Training Share，

对 100M Token 小桶和 10B Token 大桶：

重复强度完全不同。

心智模型 ②：SamplingPolicy = GradientAllocationPolicy。采样策略本质上是在给不同能力分配训练梯度。

心智模型 ③：Oversampling = SignalAmplification + DuplicateExposure。过采样能强化稀有能力，也会放大重复和过拟合风险。

心智模型 ④：SameTrainingShare ≠ SameExposure。同样的训练占比，对不同大小的 Unique Token Pool 会产生完全不同的重复曝光。

心智模型 ⑤：Eligibility ≠ Priority。Filter 决定能不能训练，Weight 决定有资格的数据训练多频繁。

心智模型 ⑥：Replay ≠ Waste。通用语料回放不是浪费 CPT 预算，而是在为通用能力做保险。

心智模型 ⑦：ConfiguredMixture ≠ ObservedMixture。真正训练分布必须从 Data Loader 和 Token Exposure 实测，而不能只看配置文件。

心智模型 ⑧：MixtureDesign = TrainingBudgetAllocation。总 Token Budget 固定时，每提高一类数据的训练份额，都意味着减少另一类数据的训练资源。
