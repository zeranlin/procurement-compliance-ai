A. 本阶段核心心智模型（前置）

  1. SharedParameters ⇒ CapabilityInterference。模型能力共享参数，学习新领域可能干扰旧能力。
  2. DomainGain ≠ NetModelGain。领域能力上涨只是收益的一面，原有能力回归必须同时计入。
  3. Overfitting ≠ Forgetting。前者是新任务泛化变差，后者是旧能力被新学习破坏。
  4. BestDomainCheckpoint ≠ BestReleaseCheckpoint。领域分数最高的模型，不一定是综合能力最适合发布的模型。
  5. WeightDistance ≠ CapabilityRegression。参数漂移只能做诊断，行为 Benchmark 才是最终证据。

Catastrophic Forgetting

模型在政府采购语料上持续更新参数以后，可能发生：

一、先锁死本阶段最重要的一句话

CPT 成功不能只看：

Domain Score 有没有上涨。

真正应该看：

DomainGain≠NetModelGain \boxed{ DomainGain \neq NetModelGain }

进一步：

NetModelGain=DomainGain−CapabilityRegressionCost \boxed{ NetModelGain = DomainGain - CapabilityRegressionCost }

这里不是要求把所有能力真的压成一个简单数字。

而是建立工程判断：

领域能力上涨，只是收益的一面；被破坏的原有能力，是必须同时计入的成本。

二、什么是 Catastrophic Forgetting？

可以把模型参数记成：

θ0 \theta_0

表示 CPT 之前的模型。

经过领域训练以后变成：

θ1 \theta_1

如果训练目标几乎只来自采购领域，

梯度会持续推动参数：

θ0→θ1 \theta_0 \rightarrow \theta_1

去适应新的领域分布。

问题在于：

原来的参数同时承担着通用语言、知识、数学、代码、指令行为等很多能力。

当这些参数为了采购分布不断调整时，

原来的某些能力可能下降。

这就是：

NewLearning可能干扰OldCapability \boxed{ NewLearning 可能干扰 OldCapability }

三、核心心智模型 ①：模型参数是“共享资产”，不是一个能力一个独立文件夹

不要把模型想象成：

采购能力
放在A文件夹

数学能力
放在B文件夹

代码能力
放在C文件夹

真实神经网络更接近：

大量能力共享同一套参数和表示空间。

所以：

SharedParameters⇒CapabilityInterference \boxed{ SharedParameters \Rightarrow CapabilityInterference }

学习采购领域时更新同一套参数，

就可能同时影响：

语言表示
注意力模式
事实关联
推理习惯
输出分布

这就是为什么：

“只是继续训练一些采购文本”

并不等于：

“只增加采购知识，不碰其他能力”。

四、Forgettting 和 Overfitting 不是一回事

这两个非常容易混。

Overfitting

过拟合

主要指：

对训练数据学得太死，泛化到同分布新样本时变差。

例如：

训练集采购条款
表现很好

新的采购条款
表现明显下降

而：

Catastrophic Forgetting

灾难性遗忘

主要指：

学习新领域以后，原本已有能力退化。

例如：

采购能力
上涨

数学
下降

通用问答
下降

代码
下降

所以：

Overfitting≠Forgetting \boxed{ Overfitting \neq Forgetting }

一个模型甚至可能：

采购领域没有过拟合，

但仍然发生明显遗忘。

五、核心心智模型 ②：Domain Improvement 和 General Retention 是两个独立坐标轴

不要只用一条：

采购分数

评估 CPT。

至少要同时看：

X轴：
Domain Gain
领域能力提升

Y轴：

通用能力保留

于是可能出现四种情况：

领域能力 通用能力 解释
↑ 稳定 理想
↑ ↓ 有收益但发生遗忘
≈ 稳定 CPT收益有限
↓ ↓ 明显失败

所以：

CPTSuccess=DomainGain+GeneralRetention \boxed{ CPTSuccess = DomainGain + GeneralRetention }

七、Forgetting Score：怎样把“忘了多少”变成可测指标？

假设某项能力 CPT 前得分：

Sbefore S_{before}

CPT 后得分：

Safter S_{after}

可以定义一个简单的绝对回归量：

Regression=Sbefore−Safter Regression = S_{before} - S_{after}

如果：

Regression>0 Regression > 0

说明能力下降。

也可以用相对回归：

RelativeRegression=Sbefore−SafterSbefore RelativeRegression = \frac{S_{before}-S_{after}} {S_{before}}

用于比较不同指标。

注意：

不同 Benchmark 的量纲不同。

所以真正工程中通常应该：

按能力单独设阈值
而不是把所有分数直接相加

十、为什么 Learning Rate 会影响遗忘？

Learning Rate：

学习率

决定参数每一步更新幅度。

概念上：

θt+1=θt−η∇θℒ \theta_{t+1} = \theta_t - \eta \nabla_\theta \mathcal{L}

其中：

η=LearningRate \eta = LearningRate

如果学习率过大，

参数可能快速偏离原始能力区域。

所以：

HigherLearningRate⇒PotentiallyFasterParameterDrift \boxed{ HigherLearningRate \Rightarrow PotentiallyFasterParameterDrift }

但要注意：

不是“学习率越小越安全”。

太小可能：

CPT 几乎学不到东西。

真正问题仍然是：

DomainGainvsRetention \boxed{ DomainGain vs Retention }

十一、Training Duration：训练越久为什么也可能遗忘越严重？

如果模型持续在一个窄领域分布上训练：

1B tokens
5B tokens
20B tokens
50B tokens

领域 Loss 可能持续下降，

但参数也会越来越适应：

采购分布。

如果通用数据完全不出现，

模型原来的分布会逐渐被弱化。

所以：

MoreCPT≠AlwaysBetterCPT \boxed{ MoreCPT \neq AlwaysBetterCPT }

训练长度必须由：

领域收益
通用回归
边际收益
预算

共同决定。

十二、Parameter Drift：参数变化大就一定遗忘严重吗？

可以定义参数变化：

Δθ=θCPT−θBase \Delta\theta = \theta_{CPT} - \theta_{Base}

也可以看某种范数：

∥Δθ∥ \|\Delta\theta\|

但必须注意：

ParameterDrift≠CapabilityRegression \boxed{ ParameterDrift \neq CapabilityRegression }

参数变化大：

不一定意味着能力一定坏。

参数变化小：

也不保证所有能力都安全。

所以 Parameter Drift 更适合作为：

诊断信号。

真正 Release 判断仍然依赖：

行为和能力评测。

十三、核心心智模型 ⑤：Weight Distance 是代理指标，Behavior Regression 才是最终证据

工程上可以监控：

权重变化

Layer-wise Drift
分层参数漂移

Embedding Drift
Embedding变化

Gradient Norm
梯度范数

但这些都属于：

Proxy Metrics

代理指标

最终真正重要的是：

模型还会不会做原来会做的事情？

所以：

WeightMetric<CapabilityBenchmark \boxed{ WeightMetric < CapabilityBenchmark }

这里的 < 表达的是：

在最终判断中的证据优先级更低。

十四、Plasticity–Stability Dilemma：CPT 的本质是“可塑性”和“稳定性”之间找平衡

这是持续学习领域非常经典的核心矛盾。

Plasticity

可塑性

表示：

模型能否学会新的领域分布。

Stability

稳定性

表示：

模型能否保留原来的能力。

如果太追求 Stability：

模型几乎不变，领域能力学不上去。

如果太追求 Plasticity：

模型学得很快，但旧能力掉得厉害。

所以：

ContinualLearning=Plasticity↔Stability \boxed{ ContinualLearning = Plasticity \leftrightarrow Stability }

这就是 CPT 真正的优化问题。

十五、核心心智模型 ⑥：CPT 不是单目标优化，而是受约束的多目标优化

我们真正希望：

DomainScore↑ DomainScore \uparrow

同时：

GeneralRegression≤Threshold GeneralRegression \leq Threshold

并且：

TrainingCost≤Budget TrainingCost \leq Budget

所以更专业地说：

MaximizeDomainGain \boxed{ Maximize \quad DomainGain }

subject to：

GeneralRegression≤AllowedThreshold \boxed{ GeneralRegression \leq AllowedThreshold }

以及：

Cost≤Budget \boxed{ Cost \leq Budget }

这比单纯说：

“CPT Loss 越低越好”

要专业得多。

二十五、本阶段最重要的 8 个核心心智模型

心智模型 ①：SharedParameters ⇒ CapabilityInterference。模型能力共享参数，学习新领域可能干扰旧能力。

心智模型 ②：DomainGain ≠ NetModelGain。领域能力上涨只是收益的一面，原有能力回归必须同时计入。

心智模型 ③：Overfitting ≠ Forgetting。前者是新任务泛化变差，后者是旧能力被新学习破坏。

心智模型 ④：BestDomainCheckpoint ≠ BestReleaseCheckpoint。领域分数最高的模型，不一定是综合能力最适合发布的模型。

心智模型 ⑤：WeightDistance ≠ CapabilityRegression。参数漂移只能做诊断，行为 Benchmark 才是最终证据。

心智模型 ⑥：Plasticity ↔︎ Stability。CPT 的核心矛盾是既要学得进去，又要保得住原能力。

心智模型 ⑦：CPTSuccess = LearnNew + KeepOld。不遗忘但没学会新领域，不算成功；领域变强但旧能力崩掉，也不算成功。

心智模型 ⑧：StopCPT ≠ WaitForLowestLoss。停止训练必须依据领域收益、能力回归、边际收益和预算共同决定。

脑中最后只留一句：

Catastrophic Forgetting 的本质不是“模型突然把知识全忘了”，而是持续在窄领域分布上更新共享参数以后，模型对新领域越来越适应，却可能逐渐偏离原有能力；因此 CPT 必须同时优化“学会新的”和“保住旧的”。
