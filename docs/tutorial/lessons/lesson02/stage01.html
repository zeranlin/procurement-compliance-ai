A. 本阶段核心心智模型（前置）

  1. Neuron = Weighted Sum + Bias + Activation。单个神经元本质上是一个可学习的打分函数。
  2. Weight 不是人工写死的业务规则，而是训练过程中由 Loss 和 Gradient 共同塑造的参数。
  3. 一层线性加权只能形成有限的线性决策边界，神经网络的能力来自多层变换与非线性组合。
  4. 神经网络的价值不是手工列出所有特征，而是让模型从数据中学习内部 Representation。
  5. 单个神经元是理解深层网络的最小单元：后面所有复杂结构仍然建立在“输入→加权→变换→输出”之上。

2. 先忘掉“神经”两个字

“神经网络”这个名字很容易让人误以为：

学习的时候，我建议先完全不要这么理解。

一个最基础的人工神经元，本质上只是在做：

即：

z=w1x1+w2x2+⋯+wnxn+b z=w_1x_1+w_2x_2+\cdots+w_nx_n+b

就这么简单。

9. 所以 Weight 可以怎样理解？

一个很实用的直觉：

Weight=模型认为某个输入对输出有多大影响 \boxed{ Weight = 模型认为某个输入对输出有多大影响 }

例如：

表示：

而：

w2=0.01 w_2=0.01

表示：

x2x_2 对当前输出几乎没什么影响。

10. 权重还有方向

如果：

wi>0 w_i>0

那么：

xi↑⇒z↑ x_i\uparrow \Rightarrow z\uparrow

如果：

wi<0 w_i<0

那么：

xi↑⇒z↓ x_i\uparrow \Rightarrow z\downarrow

也就是说：

权重不仅表示“多重要”，还表示“往哪个方向推”。

13. Bias：偏置 bb 到底是什么？

很多初学者最容易忽略：

b b

但它非常重要。

模型：

z=wTx+b z=w^Tx+b

假设所有：

xi=0 x_i=0

那么：

z=b z=b

因此 Bias 可以理解为：

模型在没有任何输入证据时的基础倾向。

14. 用风险模型理解 Bias

假设：

b=−3 b=-3

意味着：

在没有明显风险特征时，模型默认更偏向无风险。

如果：

b=2 b=2

则意味着：

即便没有明显特征，模型也天然偏向风险。

所以：

Bias=整体基线位置 \boxed{ Bias = 整体基线位置 }

15. 为什么不能没有 Bias？

假设只有：

z=w1x1+w2x2 z=w_1x_1+w_2x_2

没有：

b b

那么当：

X=[0,0] X=[0,0]

必然：

z=0 z=0

也就是说：

决策边界被强行固定穿过原点。

这会极大限制模型表达能力。

16. 一个直观例子

假设供应商风险要满足：

才判为风险。

如果没有 Bias，

只能表达：

加入：

就能写：

所以 Bias 实际上负责：
