A. 本阶段核心心智模型（前置）

  1. Backpropagation = Loss 通过 Chain Rule 沿计算图反向传播，把错误信号分配给可训练参数。
  2. Gradient ≠ Parameter Update。backward() 计算梯度，optimizer.step() 才真正改变参数。
  3. Credit Assignment 的核心是回答“最终错误应该由前面哪些参数承担多少责任”。
  4. 深层网络中的梯度是局部导数连续相乘的结果，因此会遇到梯度过小、过大和数值不稳定问题。
  5. 只有 requires_grad / 可训练参数会被优化；被冻结参数即使参与 Forward，也不应该被更新。

X→Linear→Activation→HiddenState→Logit→Prediction→Loss \boxed{ X \rightarrow Linear \rightarrow Activation \rightarrow HiddenState \rightarrow Logit \rightarrow Prediction \rightarrow Loss }

现在模型知道：

但还不知道：

这就是 Backpropagation 要解决的问题。

它的核心不是一句：

“把梯度传回去。”

而是：

Loss→找到每一个中间变量的责任→找到每一个参数的责任→Optimizer更新参数 \boxed{ Loss \rightarrow 找到每一个中间变量的责任 \rightarrow 找到每一个参数的责任 \rightarrow Optimizer更新参数 }

这就是：

Credit Assignment

责任分配。

1. 先把 Backprop 放回整个训练闭环

完整训练过程：

Batch→Forward→Loss→Backward→OptimizerStep \boxed{ Batch \rightarrow Forward \rightarrow Loss \rightarrow Backward \rightarrow OptimizerStep }

其中：

Forward：

X→Ŷ X\rightarrow \hat Y

Loss：

Ŷ,Y→L \hat Y,Y\rightarrow L

Backward：

L→∇θL L\rightarrow \nabla_\theta L

Optimizer：

θ→θ′ \theta\rightarrow\theta'

所以：

Backward本身不修改参数 \boxed{ Backward 本身不修改参数 }

它只计算：

Gradient Gradient

真正修改参数的是：

Optimizer Optimizer

2. 这是一个特别容易混淆的地方

很多初学者会说：

严格来说不够准确。

更准确是：

Backpropagation=计算梯度 \boxed{ Backpropagation = 计算梯度 }

Optimizer=利用梯度更新参数 \boxed{ Optimizer = 利用梯度更新参数 }

以后看到：

optimizer.step()

就应该知道：

3. 为什么模型需要梯度？

假设只有一个参数：

Loss：

我们想知道：

需要：

如果：

dLdw>0 \frac{dL}{dw}>0

说明：

ww 增大时 Loss 倾向增加。

所以为了降低 Loss：

应该减小。

4. 如果梯度是负数呢？

如果：

说明：

所以参数应该：

这就是 Gradient Descent：

wnew=wold−ηdLdw \boxed{ w_{new} = w_{old} - \eta \frac{dL}{dw} }

10. Backprop 的核心策略

我们不一次性问：

w→L w \rightarrow L

而是拆成：

w→z→L w \rightarrow z \rightarrow L

于是：

∂L∂w=∂L∂z∂z∂w \boxed{ \frac{\partial L}{\partial w} = \frac{\partial L}{\partial z} \frac{\partial z}{\partial w} }

这就是：

Chain Rule

链式法则。

11. Chain Rule 是 Backprop 的数学核心

如果：

y=f(g(x)) y=f(g(x))

那么：

dydx=dydgdgdx \boxed{ \frac{dy}{dx} = \frac{dy}{dg} \frac{dg}{dx} }

一句人话：

x 先影响 g，g 再影响 y。

那么：

x 对 y 的影响 = 每一段影响乘起来。

12. 用“责任传递”理解 Chain Rule

比如：

参数 w
↓
影响 z
↓
影响 Loss

如果：

w w

对：

z z

影响很大，

但：

z z

对 Loss 几乎没有影响，

那么最终：

w w

责任仍然很小。

所以：

总责任=上游责任×本地影响 \boxed{ 总责任 = 上游责任 \times 本地影响 }

13. 什么叫 Local Gradient？

例如：

这只描述：

14. Loss 对 z 的导数呢？

L=12(z−y)2 L=\frac12(z-y)^2

所以：

∂L∂z=z−y \boxed{ \frac{\partial L}{\partial z} = z-y }

现在：

z=7 z=7

y=5 y=5

所以：

∂L∂z=2 \frac{\partial L}{\partial z}=2

15. 于是 w 的梯度

Chain Rule：

∂L∂w=∂L∂z∂z∂w \frac{\partial L}{\partial w} = \frac{\partial L}{\partial z} \frac{\partial z}{\partial w}

已知：

∂L∂z=2 \frac{\partial L}{\partial z}=2

而：

∂z∂w=x=2 \frac{\partial z}{\partial w}=x=2

所以：

∂L∂w=2×2=4 \boxed{ \frac{\partial L}{\partial w} = 2\times2 = 4 }

因此为了降低 Loss：

w w

应该：

而这个又来自：

z2 z_2

所以自然只能：

53. 这不是“时间倒流”

如果暂时不熟悉矩阵：

可以把它理解成每个 Hidden Activation 与输出误差信号相乘。

56. 输出层 Bias 梯度

因为：

∂z2∂b2=1 \frac{\partial z_2}{\partial b_2}=1

所以：

∂L∂b2=δ2 \boxed{ \frac{\partial L}{\partial b_2} = \delta_2 }

Batch 情况下：

通常还会对多个样本求和或平均。

57. 怎么把梯度继续传给 Hidden Layer？

输出：

z2=W2h1+b2 z_2=W_2h_1+b_2

所以：

∂L∂h1=W2Tδ2 \boxed{ \frac{\partial L}{\partial h_1} = W_2^T\delta_2 }

这一步非常关键。

58. 为什么会乘 W2TW_2^T？

因为：

Hidden Unit 对输出影响有多大，由 W2W_2 决定。

如果某个 Hidden Dimension 到输出的权重：

≈0 \approx0

那它对最终 Loss 的责任：

也会很小。

59. 这就是 Credit Assignment

最终 Loss：

不平均怪罪所有神经元。

它会根据：

  • 谁真正影响了输出；
  • 影响方向；
  • 当前激活；
  • 后续权重；

逐层计算责任。

60. 再穿过 ReLU

有了：

∂L∂h1 \frac{\partial L}{\partial h_1}

还不能直接得到：

∂L∂z1 \frac{\partial L}{\partial z_1}

因为：

h1=ReLU(z1) h_1=ReLU(z_1)

所以：

δ1=∂L∂z1=∂L∂h1⊙ReLU′(z1) \boxed{ \delta_1 = \frac{\partial L}{\partial z_1} = \frac{\partial L}{\partial h_1} \odot ReLU'(z_1) }

61. 这里的 ⊙\odot 是什么？

表示：

Element-wise Multiplication

逐元素相乘。

也就是说：

每一个 Hidden Dimension 都乘自己的 ReLU Mask。

62. 最后第一层 Weight 梯度

z1=W1X+b1 z_1=W_1X+b_1

所以：

∂L∂W1=δ1XT \boxed{ \frac{\partial L}{\partial W_1} = \delta_1X^T }

Bias：

∂L∂b1=δ1 \boxed{ \frac{\partial L}{\partial b_1} = \delta_1 }

63. 到这里整个 Backprop 已经闭环

δ2→∇W2→∇h1→δ1→∇W1 \boxed{ \delta_2 \rightarrow \nabla W_2 \rightarrow \nabla h_1 \rightarrow \delta_1 \rightarrow \nabla W_1 }

这就是一个最基础 MLP 的 Backprop。

64. 第四个核心心智模型

心智模型 ④：每一层都同时承担两个 Backward 任务

对于一个 Linear Layer：

它要计算：

ParameterGradient \boxed{ ParameterGradient }

即：

自己的参数责任。

同时还要计算：

InputGradient \boxed{ InputGradient }

即：

应该继续向前一层传多少责任。

65. 这句话很重要

每层 Backward 不只是：

“算自己的 Weight 梯度。”

还必须：

把梯度传给前面。

否则：

网络早期层永远学不到。

=−0.7[0.80.2] = -0.7 \begin{bmatrix} 0.8&0.2 \end{bmatrix}

=[1.5−1](−0.7) = \begin{bmatrix} 1.5\\ -1 \end{bmatrix} (-0.7)

ReLU Mask：

148. 本阶段最应该会手算什么？

至少要能手算：

然后得到：

∂L∂w=(z−y)x \boxed{ \frac{\partial L}{\partial w} = (z-y)x }

149. 还应该理解二分类核心结果

Sigmoid + BCE：

∂L∂z=p−y \boxed{ \frac{\partial L}{\partial z} = p-y }

再：

∂L∂wi=(p−y)xi \boxed{ \frac{\partial L}{\partial w_i} = (p-y)x_i }

这两个公式以后会成为非常稳定的直觉锚点。

如果只保留 5 个核心专家心智模型：

心智模型 核心认知
① Gradient 是 Loss 对参数的局部敏感度 它告诉方向和局部变化率，不是业务“好坏分”
② Backprop 本质是高效执行 Chain Rule 复杂网络只是计算图更大，数学原则没变
③ 每个节点都在做“上游梯度 × 本地梯度” 这是理解所有反向传播的统一语言
④ 每一层既算自己的参数梯度，也负责把梯度继续传给前层 这就是真正的 Credit Assignment
⑤ 可训练性取决于 Gradient Flow 是否健康 Vanishing、Exploding、Residual、Initialization、Normalization 都围绕它展开
