A. 本阶段核心心智模型（前置）

  1. Gradient 告诉你局部方向，Optimizer 决定怎样利用当前和历史梯度真正更新参数。
  2. Learning Rate 是最关键的更新尺度：太大可能震荡/发散，太小可能训练极慢或停在差的区域。
  3. Adam / AdamW 会利用梯度一阶、二阶统计量做自适应更新，它不是“自动保证收敛”的魔法。
  4. Weight Decay 与 Learning Rate 是不同控制量：前者用于参数规模正则化，后者控制更新步幅。
  5. Warmup / Decay / Scheduler 属于完整优化策略的一部分，不能把“优化器名称”当成全部训练方案。

第 5 阶段，我们把最重要的一件事搞清楚了：

Backward→∇θL \boxed{ Backward \rightarrow \nabla_\theta L }

也就是说，Backpropagation 给每一个参数算出了：

当前 Loss 对这个参数的局部敏感度。

但这还没有完成学习。

假设某个参数：

w=2.0 w=2.0

梯度：

g=∂L∂w=30 g=\frac{\partial L}{\partial w}=30

现在怎么办？

直接：

w←w−30 w\leftarrow w-30

显然可能一步飞出银河系。

所以真正训练还需要一个新的决策系统：

Gradient→Optimizer→ParameterUpdate \boxed{ Gradient \rightarrow Optimizer \rightarrow ParameterUpdate }

这一阶段就是要把这件事彻底拆开。

1. 先把训练闭环补完整

现在我们已经学过：

X→Forward→Prediction→Loss→Backward X \rightarrow Forward \rightarrow Prediction \rightarrow Loss \rightarrow Backward

第 6 阶段补最后一步：

OptimizerStep \boxed{ OptimizerStep }

完整训练闭环：

Batch→Forward→Loss→Backward→Optimizer→NewParameters \boxed{ Batch \rightarrow Forward \rightarrow Loss \rightarrow Backward \rightarrow Optimizer \rightarrow NewParameters }

然后下一批数据再次开始。

2. Backward 和 Optimizer 再严格区分一次

Backward 回答：

当前Loss对每个参数的梯度是多少？ \boxed{ 当前Loss对每个参数的梯度是多少？ }

Optimizer 回答：

知道这些梯度以后，参数具体应该移动多少？ \boxed{ 知道这些梯度以后， 参数具体应该移动多少？ }

所以：

∇θL \nabla_\theta L

不是参数更新本身。

真正更新：

Δθ \Delta\theta

由 Optimizer 决定。

3. 最基础 Optimizer：Gradient Descent

最基础公式：

θt+1=θt−η∇θL \boxed{ \theta_{t+1} = \theta_t - \eta\nabla_\theta L }

其中：

θt \theta_t

是当前参数。

∇θL \nabla_\theta L

是梯度。

η \eta

就是：

Learning Rate

学习率。

4. Learning Rate 在做什么？

Gradient 告诉我们：

哪边是上坡，哪边是下坡。

Learning Rate 决定：

一步迈多远。

所以一个非常稳定的直觉是：

Gradient=Direction+LocalSlope \boxed{ Gradient = Direction+LocalSlope }

LearningRate=StepSizeScale \boxed{ LearningRate = StepSizeScale }

5. 第一个核心心智模型

心智模型 ①：梯度给方向，Optimizer 决定怎样走，Learning Rate 控制基本步长

不要把三者混成一件事。

训练实际上是：

Loss
↓
Gradient
↓
Optimizer rule
↓
Update
↓
New Parameters

6. 一个最简单数值例子

假设：

w=3 w=3

梯度：

g=4 g=4

Learning Rate：

η=0.1 \eta=0.1

则：

wnew=3−0.1(4) w_{new} = 3-0.1(4)

所以：

wnew=2.6 \boxed{ w_{new}=2.6 }

这就是最普通的一步 Gradient Descent。

7. 如果 LR = 0.01 呢？

wnew=3−0.01(4) w_{new} = 3-0.01(4)

得到：

2.96 \boxed{ 2.96 }

方向一样。

但走得：

更小。

8. 如果 LR = 1 呢？

wnew=3−1(4) w_{new} = 3-1(4)

得到：

−1 -1

可能直接：

越过低 Loss 区域。

所以 Learning Rate 是训练里最重要的超参数之一。

9. 为什么不能直接找到 Loss 最低点？

因为真实神经网络可能有：

109 10^9

甚至更多参数。

Loss：

L(θ1,θ2,…,θn) L(\theta_1,\theta_2,\ldots,\theta_n)

存在于一个极高维空间。

我们不能：

把所有参数组合都试一遍。

只能利用当前局部信息：

∇L \nabla L

一点一点走。

10. Loss Landscape

可以把：

L(θ) L(\theta)

想成一个地形：

Loss Landscape

损失地形。

低处：

Loss 小。

高处：

Loss 大。

训练相当于：

在超高维山地里寻找低地。

11. 一维时比较简单

例如：

L(w)=(w−3)2 L(w)=(w-3)^2

最低点：

w=3 w=3

导数：

dLdw=2(w−3) \frac{dL}{dw} = 2(w-3)

如果：

w=5 w=5

梯度：

4 4

于是向左走。

12. 但神经网络不是一维

真实参数可能：

θ∈ℝ7B \theta\in\mathbb R^{7B}

Loss Landscape 不是二维山谷。

而是：

数十亿维的复杂几何空间。

所以所谓“往下走”：

−∇L -\nabla L

本质是：

当前点最陡下降方向。

13. Gradient Descent 为什么叫“Descent”？

因为：

−∇L -\nabla L

在一阶近似下，是：

Loss 下降最快的局部方向。

注意：

局部

不是说：

一定通往全局最优。

14. Taylor Expansion 的直觉

在当前参数：

θ \theta

附近，小幅改变：

Δθ \Delta\theta

有：

L(θ+Δθ)≈L(θ)+∇LTΔθ L(\theta+\Delta\theta) \approx L(\theta) + \nabla L^T\Delta\theta

如果：

Δθ=−η∇L \Delta\theta=-\eta\nabla L

那么：

∇LTΔθ=−η∥∇L∥2 \nabla L^T\Delta\theta = -\eta\|\nabla L\|^2

通常为负。

所以小步时：

Loss 倾向下降。

15. 这也解释为什么步长不能无限大

上面的推导依赖：

局部线性近似。

如果一步：

Δθ \Delta\theta

特别大，

那么：

当前 Gradient 对远处已经不再可靠。

这就是为什么：

LearningRate LearningRate

必须受控制。

16. 一个政府采购模型例子

假设风险模型某个抽象参数：

wlocal w_{local}

表示某种对“地域性条件模式”的敏感方向。

当前 Batch：

模型大量漏掉真正风险样本。

Backward 给：

g=−0.6 g=-0.6

如果：

η=0.01 \eta=0.01

那么：

Δw=−0.01(−0.6)=+0.006 \Delta w = -0.01(-0.6) = +0.006

于是参数：

略微加强这一方向。

17. 为什么训练需要很多 Step？

因为每一次更新通常都很小：

Δθ \Delta\theta

模型不会：

看一批数据就完全重写知识。

而是：

MillionsofSmallUpdates \boxed{ Millions\ of\ Small\ Updates }

逐渐塑造参数。

18. Step 到底是什么？

通常一次：

optimizer.step() optimizer.step()

称为一个：

Optimization Step

或者：

Global Step

即：

参数真正更新一次。

19. Step 和 Batch 不一定一一对应

没有 Gradient Accumulation 时：

1 Batch
→ 1 Backward
→ 1 Optimizer Step

但如果 Gradient Accumulation = 8：

Micro Batch 1 → Backward
Micro Batch 2 → Backward
...
Micro Batch 8 → Backward
↓
Optimizer Step

所以：

8个MicroBatch→1个OptimizerStep \boxed{ 8个MicroBatch \rightarrow 1个OptimizerStep }

20. 第二个核心心智模型

心智模型 ②：真正的训练时间尺度是 Optimizer Step，而不仅仅是“看了多少 Batch”

例如：

Learning Rate Scheduler

通常很多情况下按照：

OptimizerStep OptimizerStep

推进。

不是按照：

每一次 Forward。

21. 最理想的 Gradient 是什么？

假设训练集有：

N N

个样本。

总 Loss：

L(θ)=1N∑i=1NLi(θ) L(\theta) = \frac1N \sum_{i=1}^N L_i(\theta)

完整梯度：

∇L=1N∑i∇Li \boxed{ \nabla L = \frac1N \sum_i\nabla L_i }

这叫：

Full-Batch Gradient

22. 问题是什么？

如果：

N=100,000,000 N=100,000,000

每更新一次参数都必须：

把全部数据跑一遍。

成本太高。

所以现实训练：

使用部分样本估计梯度。

23. Stochastic Gradient Descent

严格历史意义下：

SGD

可以指：

每次随机取一个或小批样本估计梯度。

现代工程里 SGD 这个名字经常对应：

Mini-batch SGD。

24. Mini-batch 梯度

假设 Batch：

B B

则：

gB=1|B|∑i∈B∇Li g_B = \frac1{|B|} \sum_{i\in B} \nabla L_i

用：

gB g_B

近似：

∇Lfull \nabla L_{full}

25. 这个近似有噪声

不同 Batch：

B1,B2 B_1,B_2

可能得到：

g1≠g2 g_1\neq g_2

所以参数路线不是：

平滑直线下山。

更像：

一边晃一边往低处走。

26. 这听起来像缺点，但不全是

Gradient Noise 有时可以：

帮助优化过程跳出一些狭窄区域。

因此训练中的随机性：

并不全是坏东西。

27. Batch Size 和 Gradient Noise

通常：

BatchSize↑ BatchSize\uparrow

梯度估计：

更稳定。

BatchSize↓ BatchSize\downarrow

梯度：

更 noisy。

所以：

BatchSize也会改变Optimizer看到的世界 \boxed{ BatchSize 也会改变Optimizer看到的世界 }

28. 这就是为什么改变 Batch Size 不能只看显存

它不仅是：

GPU 工程参数。

也会改变：

OptimizationDynamics OptimizationDynamics

即训练动力学。

29. 假设 Loss Landscape 是一个狭长山谷

横向：

很陡。

纵向：

很缓。

你真正想沿山谷：

向前走。

但 Gradient 每一步都可能：

强烈左右摆动。

30. 一个二维直觉

假设：

L(w1,w2)=100w12+w22 L(w_1,w_2) = 100w_1^2+w_2^2

对：

w1 w_1

方向非常陡。

对：

w2 w_2

方向很缓。

31. Gradient

∇L=[200w12w2] \nabla L = \begin{bmatrix} 200w_1\\ 2w_2 \end{bmatrix}

所以：

w1 w_1

方向的梯度可能远大于：

w2 w_2

训练就会：

在陡峭方向来回震荡。

32. 这就是 Optimization Geometry

同样的一个全局 LR：

η \eta

要同时服务：

很陡的维度和很平的维度。

非常困难。

33. 如果 LR 为照顾陡峭方向设得很小

那么平坦方向：

走得极慢。

如果 LR 为平坦方向设得很大：

陡峭方向可能爆炸。

这就是优化器要面对的问题之一。

34. Momentum 想解决什么？

基本思路：

不要只看当前这一批数据的 Gradient。

还参考：

最近一段时间的方向。

这叫：

Momentum

动量。

35. 一个常见形式

vt=βvt−1+gt v_t = \beta v_{t-1} + g_t

然后：

θt+1=θt−ηvt \theta_{t+1} = \theta_t - \eta v_t

其中：

vt v_t

可以理解为：

带历史记忆的更新方向。

36. 另一种等价风格

有些教材写：

vt=βvt−1+(1−β)gt v_t = \beta v_{t-1} + (1-\beta)g_t

本质：

都是在做梯度的指数移动平均。

具体缩放约定不同。

37. 什么是 Exponential Moving Average？

EMA：

mt=βmt−1+(1−β)xt m_t = \beta m_{t-1} + (1-\beta)x_t

最近数据：

权重更高。

很久以前的数据：

权重指数衰减。

38. 如果 β=0.9\beta=0.9

新值：

10% 10\%

进入当前平均。

历史：

90% 90\%

继续保留。

这就让 Optimizer：

有了“惯性”。

39. 第三个核心心智模型

心智模型 ③：Momentum 不是让参数“走得更猛”，核心是积累持续方向、抵消高频抖动

如果连续很多 Batch 都说：

向右。

Momentum：

会越来越确信向右。

如果左右交替：

会部分抵消。

优点：

缺点：

所以：

45. Nesterov Momentum

你以后可能看到：

Nesterov Momentum

核心直觉：

普通 Momentum 是看当前位置 Gradient 再走。

Nesterov：

先大致看一下按照动量会走到哪里，再在那里估计修正方向。

46. 现在不需要死背 Nesterov 公式

这一阶段更重要的是建立：

Optimizer可以利用GradientHistory \boxed{ Optimizer 可以利用GradientHistory }

而不是：

只使用当前一步。

Adam 也是从这里继续发展。

47. SGD 的一个限制

普通 SGD：

Δθi=−ηgi \Delta\theta_i = -\eta g_i

所有参数共用：

η \eta

只是 Gradient 本身不同。

48. 现实中不同维度梯度尺度差异可能巨大

参数 A：

gA=0.0001 g_A=0.0001

参数 B：

gB=100 g_B=100

同一个 LR：

很难同时合适。

于是出现：

Adaptive Optimizer

自适应优化器。

49. AdaGrad 的核心思想

某个参数历史梯度一直很大：

那就自动缩小它未来的有效步长。

某个参数梯度一直很小：

相对允许走大一些。

50. 累积平方梯度

st=st−1+gt2 s_t = s_{t-1} + g_t^2

然后：

θt+1=θt−ηgtst+ϵ \theta_{t+1} = \theta_t - \eta \frac{g_t} {\sqrt{s_t}+\epsilon}

51. 为什么平方？

因为：

gt2 g_t^2

只关心：

梯度幅度。

不关心：

正负方向。

所以：

st s_t

反映该参数历史上：

梯度有多大。

52. AdaGrad 的问题

因为：

st s_t

一直累计，只增不减。

训练时间很长以后：

st \sqrt{s_t}

越来越大。

于是有效 LR：

越来越小。

最终可能：

几乎走不动。

53. RMSProp 的改进

不要把从训练开始以来的平方梯度：

永久累加。

而是做：

Exponential Moving Average

54. 公式直觉

vt=βvt−1+(1−β)gt2 v_t = \beta v_{t-1} + (1-\beta)g_t^2

更新：

θt+1=θt−ηgtvt+ϵ \boxed{ \theta_{t+1} = \theta_t - \eta \frac{g_t} {\sqrt{v_t}+\epsilon} }

55. 这相当于什么？

每个参数都有一个：

自己的梯度尺度估计器。

Gradient 经常很大：

分母变大。

有效步长：

自动变小。

56. ϵ\epsilon 是干什么的？

例如：

ϵ=10−8 \epsilon=10^{-8}

主要用于：

数值稳定。

避免：

vt=0 \sqrt{v_t}=0

时除以 0。

57. 现在终于到最常见的 Adam

Adam

可以粗略理解为：

Momentum+AdaptiveScale \boxed{ Momentum + AdaptiveScale }

即同时维护：

梯度一阶统计量。

和：

梯度平方的二阶统计量。

58. 一阶矩

mt=β1mt−1+(1−β1)gt m_t = \beta_1m_{t-1} + (1-\beta_1)g_t

它像：

Momentum。

记录：

梯度平均方向。

59. 二阶矩

vt=β2vt−1+(1−β2)gt2 v_t = \beta_2v_{t-1} + (1-\beta_2)g_t^2

记录：

梯度平方的移动平均。

也就是：

近期梯度尺度。

60. Adam 核心更新

经过偏差修正后，大致：

θt+1=θt−ηm̂tv̂t+ϵ \boxed{ \theta_{t+1} = \theta_t - \eta \frac{\hat m_t} {\sqrt{\hat v_t}+\epsilon} }

这就是 Adam 的核心。

61. 为什么分子是 mtm_t？

它告诉：

66. 什么叫 Bias Correction？

初始化时：

m0=0 m_0=0

v0=0 v_0=0

训练早期 EMA：

会偏向 0。

Adam 会做：

m̂t=mt1−β1t \hat m_t = \frac{m_t}{1-\beta_1^t}

以及：

v̂t=vt1−β2t \hat v_t = \frac{v_t}{1-\beta_2^t}

进行修正。

67. 为什么第一步尤其需要修正？

例如：

β1=0.9 \beta_1=0.9

第一步：

m1=0.1g1 m_1=0.1g_1

如果不修正：

看起来梯度平均只有真实值的十分之一。

修正：

0.1g11−0.9=g1 \frac{0.1g_1}{1-0.9} = g_1

就恢复合理尺度。

偏差修正：

=0.004 =0.004

忽略很小的 ϵ\epsilon：

m̂1v̂1=22=1 \frac{\hat m_1}{\sqrt{\hat v_1}} = \frac2{2} = 1

73. 先说 Weight Decay

我们不希望某些权重：

一个直觉办法：

每一步都稍微把参数往 0 拉一点。

例如：

这就是：

权重衰减的直觉。

74. 为什么叫 Decay？

即使某一步：

只要 Weight Decay 存在，

参数：

仍会略微缩小。

经典目标中也可以加入：

Ltotal=Ldata+λ2∥θ∥2 L_{total} = L_{data} + \frac{\lambda}{2}\|\theta\|^2

于是梯度：

∇Ltotal=∇Ldata+λθ \nabla L_{total} = \nabla L_{data} + \lambda\theta

但是：

在 Adam 这种 adaptive optimizer 里，两者不再简单等价。

分离。

本阶段五个最重要的专家心智模型

心智模型 核心认知
① Gradient、Optimizer、Learning Rate 是三件不同的事 Gradient 提供局部信息，Optimizer 定更新规则，LR 控制基本步长
② 真正的训练时间尺度是 Optimizer Step Micro-batch、Backward 次数和参数更新次数必须区分
③ Momentum 是历史方向记忆 主要作用是积累一致方向、抑制高频抖动
④ Adam 是方向统计 + 梯度尺度自适应 每个参数拥有动态有效步长，而不是简单统一乘 LR
⑤ AdamW 把任务梯度和 Weight Decay 分开 优化数据目标与正则化参数规模是不同机制

如果只记三个公式

第一个：

θt+1=θt−ηgt \boxed{ \theta_{t+1} = \theta_t-\eta g_t }

这是最基础 SGD。

第二个：

mt=β1mt−1+(1−β1)gt \boxed{ m_t = \beta_1m_{t-1} + (1-\beta_1)g_t }

这是方向历史。

第三个：

vt=β2vt−1+(1−β2)gt2 \boxed{ v_t = \beta_2v_{t-1} + (1-\beta_2)g_t^2 }

这是梯度尺度历史。

Adam：

就把它们组合起来。

如果只记一句话

Backprop告诉模型“哪里该改”，Optimizer决定“怎么改、改多少、是否参考过去”。 \boxed{ Backprop告诉模型“哪里该改”， Optimizer决定“怎么改、改多少、是否参考过去”。 }
