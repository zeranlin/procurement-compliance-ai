A. 本阶段核心心智模型（前置）

  1. No Activation ⇒ Deep Linear Model。没有非线性激活函数，多层线性层可以合并成一个线性变换。
  2. Activation Function 的核心作用是引入非线性，使网络能够表示弯曲、分段和更复杂的决策边界。
  3. ReLU / GELU / SiLU 的差异主要影响数值形状、梯度流和优化行为，不代表某一种激活函数“更懂政府采购”。
  4. 激活函数会影响梯度是否容易传播，因此它既是表达能力问题，也是训练稳定性问题。
  5. 对预训练模型而言，Activation 是架构的一部分，不能因为“另一个函数看起来更好”就随意替换。

如果每一层都只是 WX+bWX+b，那把 2 层、20 层、200 层叠起来，真的会变聪明吗？

答案是：

不会 \boxed{ 不会 }

真正让神经网络能够表达复杂规律的关键组件之一，就是今天的主角：

ActivationFunction \boxed{ Activation\ Function }

1. 先把第二阶段放到总路线里

第二课目前走到：

这一阶段我们重点理解：

Sigmoid→Tanh→ReLU→GELU→SiLU \boxed{ Sigmoid \rightarrow Tanh \rightarrow ReLU \rightarrow GELU \rightarrow SiLU }

但真正重要的不是背函数名字。

而是回答：

为什么神经网络必须有非线性？

2. 先复习上一阶段的核心公式

一个神经元：

z=w1x1+w2x2+⋯+wnxn+b z=w_1x_1+w_2x_2+\cdots+w_nx_n+b

向量形式：

z=WTX+b \boxed{ z=W^TX+b }

多个神经元组成 Linear Layer：

Z=WX+b \boxed{ Z=WX+b }

这本质上都是：

Linear / Affine Transformation

线性或仿射变换。

3. 如果连续放两个 Linear Layer 会怎样？

第一层：

h=W1X+b1 h=W_1X+b_1

第二层：

y=W2h+b2 y=W_2h+b_2

代入第一层：

y=W2(W1X+b1)+b2 y = W_2(W_1X+b_1)+b_2

展开：

y=W2W1X+W2b1+b2 y = W_2W_1X + W_2b_1 + b_2

重新定义：

W′=W2W1 W'=W_2W_1

b′=W2b1+b2 b'=W_2b_1+b_2

于是：

y=W′X+b′ \boxed{ y=W'X+b' }

4. 一个非常重要的结论

两个线性层：

Linear→Linear Linear \rightarrow Linear

Linear Linear

那么：

100 100

层呢？

仍然可以不断合并。

所以：

Linear∘Linear∘Linear=Linear \boxed{ Linear \circ Linear \circ Linear = Linear }

5. 这意味着什么？

假设你造一个：

1000 层神经网络。

但是每一层只有：

WX+b WX+b

最终它在数学表达能力上：

仍然只是一个大线性模型。

这句话非常重要：

Depthalone≠Complexity \boxed{ Depth\ alone \neq Complexity }

单纯增加深度，并不会自动产生复杂表达能力。

6. 那么 Activation 在哪里加入？

真正的神经网络通常这样：

z=WTX+b z=W^TX+b

然后：

a=f(z) \boxed{ a=f(z) }

这里：

f f

就是：

Activation Function

激活函数。

于是一个神经元变成：

a=f(WTX+b) \boxed{ a=f(W^TX+b) }

7. 为什么叫 Activation？

历史上可以把它理解成：

一个神经元接收到足够刺激以后是否“激活”。

但对于我们学习机器学习，最好先把生物学比喻放一边。

它最重要的数学职责是：

引入非线性 \boxed{ 引入非线性 }

8. 第一个核心心智模型

心智模型 ①：Activation 的核心不是“激活神经元”，而是“打破线性”

记住：

Linear+Activation \boxed{ Linear + Activation }

才是真正开始产生复杂表达能力的组合。

如果没有 Activation：

DeepNetwork Deep\ Network

可以坍缩成：

9. 什么叫“非线性”？

简单说：

如果：

f(ax+by)=af(x)+bf(y) f(ax+by) = af(x)+bf(y)

总成立，它属于线性关系。

而像：

x2 x^2

sinx \sin x

max(0,x) \max(0,x)

通常都不是线性的。

例如 ReLU：

f(x)=max(0,x) f(x)=\max(0,x)

就是非常简单的非线性函数。

10. 一个看起来很简单的函数，为什么这么重要？

ReLU：

ReLU(x)=max(0,x) \boxed{ ReLU(x)=\max(0,x) }

如果：

x<0 x<0

输出：

0 0

如果：

x>0 x>0

输出：

x x

看起来简单得离谱。

但这个“折一下”：

就已经打破了纯线性关系。

单个线性函数只能画：

一条直线。

但多个：

很多段不同斜率的折线。

二维空间里：

高维空间里：

13. 一个政府采购例子

假设：

如果风险不是简单：

而可能是：

这更像：

也就是说：

当：

输出：

14. 现实业务中大量存在“阈值效应”

例如项目条件：

有一点严格，不一定有问题。

但当多个限制达到某种程度以后：

竞争影响显著增强。

这就是：

线性模型很难自然表示这种：

非线性函数则非常适合。

而可能具有：

18. 第二个核心心智模型

心智模型 ②：Activation 让网络能够不断“重新切割输入空间”

一个 Linear Layer：

画一个超平面。

Activation：

把空间折叠、截断或重新映射。

下一层再：

重新组合。

于是：

Linear→Fold→Linear→Fold \boxed{ Linear \rightarrow Fold \rightarrow Linear \rightarrow Fold }

最终可以形成非常复杂的 Decision Boundary。

19. 先学最经典的 Sigmoid

第一课已经见过：

σ(x)=11+e−x \boxed{ \sigma(x)=\frac{1}{1+e^{-x}} }

它把：

(−∞,+∞) (-\infty,+\infty)

压缩到：

(0,1) (0,1)

20. Sigmoid 的几个典型值

当：

x=−5 x=-5

大约：

0.007 0.007

当：

x=0 x=0

得到：

0.5 0.5

当：

x=5 x=5

大约：

0.993 0.993

它是一个：

S 型曲线。

21. Sigmoid 为什么适合二分类输出层？

假设模型最后输出：

z z

我们需要：

RiskScore∈(0,1) RiskScore\in(0,1)

那么：

p=σ(z) p=\sigma(z)

就非常自然。

所以：

BinaryClassification \boxed{ Binary\ Classification }

中 Sigmoid 经常出现在：

最后一层输出。

22. 但 Sigmoid 作为隐藏层 Activation 有问题

最主要的问题之一：

Saturation

饱和。

当：

x≫0 x\gg0

Sigmoid 接近：

1 1

当：

x≪0 x\ll0

接近：

0 0

这两个区域曲线几乎变平。

23. 为什么“变平”是问题？

因为训练靠：

Gradient Gradient

梯度。

如果曲线很平：

dσdx≈0 \frac{d\sigma}{dx} \approx0

那么：

梯度很小。

反向传播到前面的参数：

更新非常弱。

24. Sigmoid 的导数

一个非常漂亮的公式：

σ′(x)=σ(x)(1−σ(x)) \boxed{ \sigma'(x) = \sigma(x)(1-\sigma(x)) }

最大值发生在：

σ(x)=0.5 \sigma(x)=0.5

也就是：

x=0 x=0

此时最大导数：

0.25 0.25

25. 这意味着什么？

即使最理想位置：

Gradient Gradient

最多还要乘：

0.25 0.25

如果连续很多层 Sigmoid：

0.25×0.25×0.25×⋯ 0.25 \times 0.25 \times 0.25 \times\cdots

很快变得非常小。

这就是：

Vanishing Gradient

梯度消失。

26. 一个简单数字直觉

假设每层梯度大约乘：

0.2 0.2

连续 10 层：

0.210 0.2^{10}

约等于：

0.0000001024 0.0000001024

也就是说：

后层还有明显误差信号，

传到前几层以后：

几乎没了。

27. 这会造成什么？

靠近输出层：

学得比较快。

网络早期层：

几乎不更新。

深度网络就很难训练。

这也是早期深度神经网络发展中的一个核心难题。

28. 第三个核心心智模型

心智模型 ③：Activation 不只决定表达能力，也决定梯度能不能顺利流动

所以选择 Activation 时要看两件事：

ForwardExpressiveness \boxed{ Forward\ Expressiveness }

以及：

BackwardGradientFlow \boxed{ Backward\ GradientFlow }

一个函数前向表达很好，

但梯度传播极差：

训练仍然可能失败。

29. 第二个经典函数：Tanh

公式：

tanh(x)=ex−e−xex+e−x \boxed{ \tanh(x) = \frac{e^x-e^{-x}} {e^x+e^{-x}} }

输出范围：

(−1,1) (-1,1)

30. Tanh 和 Sigmoid 最大区别之一

Sigmoid 输出：

(0,1) (0,1)

而 Tanh：

(−1,1) (-1,1)

也就是说：

Tanh 是以 0 为中心的。

这通常比 Sigmoid 作为隐藏层更好一些。

31. 为什么 Zero-centered 有帮助？

如果激活值全部：

>0 >0

梯度方向有时容易产生不理想的偏移。

而 Tanh 同时有：

正值和负值。

优化过程通常更自然。

不过这是优化层面的直觉，不需要现在过度展开。

32. Tanh 仍然有 Saturation

当：

x≫0 x\gg0

Tanh：

→1 \to1

当：

x≪0 x\ll0

Tanh：

→−1 \to-1

两端一样：

梯度接近 0。

所以它仍然存在：

VanishingGradient VanishingGradient

问题。

33. 然后 ReLU 出现了

ReLU：

ReLU(x)=max(0,x) \boxed{ ReLU(x)=\max(0,x) }

导数大致：

ReLU′(x)={0,x<01,x>0 ReLU'(x) = \begin{cases} 0,&x<0\\ 1,&x>0 \end{cases}

在 00 点严格数学上不可导，但工程中可以选择一个方便的值处理。

34. ReLU 最大优势是什么？

正区间：

x>0 x>0

导数：

1 1

所以梯度不像 Sigmoid 那样一直被压缩。

这让深层网络：

更容易训练。

35. ReLU 还有计算简单的优点

Sigmoid 需要：

e−x e^{-x}

Tanh 也涉及指数运算。

ReLU：

max(0,x) \max(0,x)

计算非常直接。

在大规模神经网络中：

简单操作乘以几十亿次，就很有意义。

36. ReLU 还会产生稀疏激活

对于：

x<0 x<0

输出直接：

0 0

意味着某些神经元在某些输入上：

完全关闭。

这种：

Sparse Activation

有时会形成有用的表示特性。

37. 政府采购的直觉例子

假设某个隐藏神经元概念上学习：

“不合理本地限制信号”。

如果当前条款完全没有这种模式：

z<0 z<0

经过 ReLU：

0 0

这个特征：

不向下一层继续贡献。

如果相关信号明显：

则：

继续传递。

38. 但是 ReLU 也有问题

最经典：

Dying ReLU

“死亡 ReLU”。

如果某个神经元长期：

那么：

ReLU(z)=0 ReLU(z)=0

而梯度：

0 0

它可能以后：

很难再被训练回来。

39. 为什么神经元会“死”？

假设一次参数更新太激进：

b b

变得非常负。

于是无论输入怎样：

Wx+b<0 Wx+b<0

那么这个神经元永远：

0 0

梯度也：

0 0

所以它基本停止学习。

40. 这和 Learning Rate 也有关系

如果：

LearningRate LearningRate

过大，

参数更新幅度太猛，

某些 ReLU 神经元更容易跑入：

这再次说明：

例如：

负区间不再完全：

0 0

而是：

所以梯度仍然有：

0.01 0.01

神经元不容易彻底“死亡”。

44. 进入现代 Transformer 常见的 GELU

公式的一种定义：

GELU(x)=xΦ(x) \boxed{ GELU(x) = x\Phi(x) }

其中：

Φ(x) \Phi(x)

是标准正态分布的累积分布函数。

45. GELU 的直觉是什么？

ReLU 是硬切：

x<0⇒0 x<0\Rightarrow0

GELU 更像：

平滑地决定保留多少输入。

例如略微负的值：

不一定完全砍掉。

较大的正值：

基本保留。

所以它比 ReLU：

更平滑。

46. GELU 可以粗略理解成“软门”

ReLU：

负值 → 直接关掉
正值 → 直接通过

GELU：

负很多 → 大多压掉
接近0 → 部分通过
正很多 → 大多保留

它更像：

SoftGating \boxed{ Soft\ Gating }

47. 为什么 Transformer 喜欢 GELU？

早期 Transformer 系列大量采用 GELU，因为它：

平滑、可微，并且在深层网络中表现很好。

后来的许多架构也使用其它函数。

所以不要形成：

“Transformer = GELU”

这种绝对印象。

架构会变化。

48. 另一个现代常见函数：SiLU

SiLU：

SiLU(x)=xσ(x) \boxed{ SiLU(x) = x\sigma(x) }

也常叫：

Swish

49. SiLU 长什么样？

它和 ReLU 类似：

正值大部分保留。

但负值：

不会全部变成 0。

而会留下小的负输出。

同时整体：

很平滑。

现代很多 Transformer/LLM 架构会使用：

尤其配合：

或：

52. Activation 和“开关”有什么关系？

很多激活函数都可以理解成：

例如 ReLU：

完全关闭。

GELU / SiLU：

更柔和地调节。

所以：

也是一个很有用的直觉。

53. 但不要误解成“一神经元一个规则”

例如一个神经元高激活：

不一定就明确等于“本地限制”。

真实深度网络中：

一个概念往往分布在多个神经元和维度之间。

同时一个神经元也可能参与：

多个概念。

这叫：

54. 为什么多个简单非线性可以产生复杂能力？

这是深度学习最迷人的地方之一。

单个 ReLU：

非常简单。

但成千上万个 ReLU：

在不同方向、不同阈值上切割空间。

再叠很多层：

就可以组合成非常复杂的函数。

55. 可以把它想成“折纸”

原始输入空间：

很难用一条线分开。

第一层：

折一次。

第二层：

再折。

第三层：

再重新组合。

最终：

原本复杂交错的数据，在新表示空间里可能变得容易分开。

这只是直觉比喻，但非常有用。

56. 第四个核心心智模型

心智模型 ④：深度网络不是在原始空间硬画一条复杂线，而是在不断改变“表示空间”

我们最终不是简单：

而是：

X→H1→H2→H3→Y X \rightarrow H_1 \rightarrow H_2 \rightarrow H_3 \rightarrow Y

每一个：

都是新的 Representation。

57. 政府采购例子：第一层可能学什么？

假设原始表示包含大量语言特征。

第一层概念上可能形成：

第二层可能组合成：

更深层再组合：

资格限制是否与履约能力存在合理关联。

这是帮助理解的概念模型，不代表真实神经元会严格一一对应这些标签。

Deep Learning 的“深”不仅仅表示：

更重要的是：

所以专家不会只因为：
