A. 本阶段核心心智模型（前置）

  1. Hidden Layer ≠ Human Rule Table。隐藏层不是一张可直接阅读的专家规则表。
  2. Representation 是分布式的：一个业务概念通常由很多维度共同编码，而不是对应某一个神经元。
  3. Depth 的价值来自多层函数复合，让模型逐步把表面输入转换成更抽象的内部特征。
  4. 更深 ≠ 自动更好；只有在优化稳定、数据足够、架构合理时，深度才可能转化为能力。
  5. “模型内部形成了某种表示”是需要通过探针、消融和行为实验验证的工程判断，不能只凭直觉解释。

6. 第一个核心心智模型

心智模型 ①：Hidden Layer 的作用不是“多算几遍”，而是创造新的表示

第二层不是继续看原始 X，

15. 为什么 WW 有这么多数字？

因为每一个 Hidden Neuron：

都需要决定上一层每个输入对自己的影响。

例如：

Neuron 1：

h1=f(w11x1+w12x2+w13x3+b1) h_1=f(w_{11}x_1+w_{12}x_2+w_{13}x_3+b_1)

Neuron 2：

h2=f(w21x1+w22x2+w23x3+b2) h_2=f(w_{21}x_1+w_{22}x_2+w_{23}x_3+b_2)

……

每一个神经元都有不同：

W W

所以能观察输入的不同方向。

17. 一个重要警告

不要认为：

一定就是：

真实模型内部往往是：

即：

一个概念分布在多个维度里。

同时：

一个维度也可能参与表示多个概念。

因此：

Neuron≠HumanConcept \boxed{ Neuron\neq HumanConcept }

因为现实概念非常复杂。

23. 但维度越大越好吗？

不一定。

更大的 Hidden Dimension：

提供更大表达空间。

但也会带来：

  • 更多参数；
  • 更多计算；
  • 更多显存；
  • 更高过拟合可能；
  • 更多数据需求。

所以仍然是：

CapacityvsCost \boxed{ Capacity\ vs\ Cost }

32. 第三个核心心智模型

心智模型 ③：Width 决定“这一层能同时表示多少”，Depth 决定“能进行多少级组合”

38. 什么是 Feature Reuse？

一个底层模式可能被多个高级任务共享。

例如模型识别：

这个比较/约束语义。

它既可能参与：

  • 注册资本限制；
  • 业绩数量限制；
  • 人员数量限制；
  • 营收限制。

所以底层 Feature：

可以被多个高级概念重复使用。

H1=ReLU(z1) H_1=ReLU(z_1)

得到：

H1=[10] \boxed{ H_1= \begin{bmatrix} 1\\ 0 \end{bmatrix} }

原来的 3 维输入：

[1,0,1] [1,0,1]

已经变成新的 2 维表示：

[1,0] [1,0]

109. 再进入第二层

假设：

W2=[2−1] W_2= \begin{bmatrix} 2&-1 \end{bmatrix}

b2=−0.5 b_2=-0.5

那么：

z2=2(1)−1(0)−0.5 z_2 = 2(1)-1(0)-0.5

z2=1.5 \boxed{ z_2=1.5 }

110. 输出 Sigmoid

p=σ(1.5) p=\sigma(1.5)

大约：

0.818 \boxed{ 0.818 }

所以：

Input
[1,0,1]

↓

Hidden
[1,0]

↓

Logit
1.5

↓

Risk Score
0.818

这就是一个完整 Forward Pass。

111. 这次你应该特别注意什么？

不是：

最终 0.818。

而是中间：

[1,0,1]→[1,0] \boxed{ [1,0,1] \rightarrow [1,0] }

这个转换。

因为：

这就是 Representation Learning 最小版本。

112. 如果换一个输入

会完全不同。

为不同输入构造不同表示。

113. 为什么需要多层 Hidden？

一层：

可以学一次非线性转换。

多层：

H1=f1(W1X+b1) H_1=f_1(W_1X+b_1)

H2=f2(W2H1+b2) H_2=f_2(W_2H_1+b_2)

H3=f3(W3H2+b3) H_3=f_3(W_3H_2+b_3)

意味着：

对表示连续加工。

114. 每层可以把上一层当成“新输入”

第一层：

不知道最终答案，只负责构造有用 Feature。

第二层：

不再直接面对原始数据，而面对第一层 Feature。

第三层：

再组合第二层 Feature。

所以：

Abstractionbuildsonabstraction \boxed{ Abstraction\ builds\ on\ abstraction }

更进一步：

也就是不断：

如果两个样本的 Hidden Vector：

就会衡量这种相似性。

121. 第七个核心心智模型

心智模型 ⑦：好的表示会让“语义上相似的东西在向量空间里更容易被一起处理”
