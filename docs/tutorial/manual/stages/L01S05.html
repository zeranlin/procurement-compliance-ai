主要内容 / 核心心智模型

  1. Batch 是对整体数据分布的有噪声局部估计。
  2. Epoch 是训练深度，不是模型能力分数。
  3. Gradient、Optimizer、Learning Rate 是三个不同角色。
  4. 训练本质是随机/有噪声优化，曲线抖动不等于失败。
  5. Monitoring 本身就是训练的一部分，没有日志就难以诊断。
